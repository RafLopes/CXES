Site institucional do Clube de Xadrez Erbo Stenzel.

🔗 **Acessar**: https://clubeerbostenzelxadrez.web.app/

## Páginas

- **Início** e **Sobre** o clube
- **Membros**: perfis dos membros com foto e descrição
- **Torneios**: resultados dos torneios do clube, com dados da API do Chess.com
- **Palestras** e **Galeria** de fotos

## Tecnologias

- HTML, CSS e JavaScript puros
- Integração com a API pública do Chess.com
- Firebase (Hosting e banco de dados)
